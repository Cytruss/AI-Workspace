# ADR-0002: License the Repository Under Apache-2.0

## Status

Accepted

## Date

2026-08-23

## Context

The project is intended for public, private, and commercial use. Contributors and adopters need a permissive license with clear treatment of relevant patent claims.

## Decision

License the repository under the Apache License 2.0.

## Alternatives considered

- MIT, for a shorter and widely recognized permissive license.
- MPL-2.0, for file-level copyleft.
- GPL-3.0, for strong copyleft.

## Reasons

- Apache-2.0 permits private, commercial, and open-source use.
- Its explicit patent grant and patent-termination terms reduce ambiguity for contributors and downstream users.
- Attribution and change-notice obligations remain compatible with broad adoption.

## Consequences

- Distributed copies must preserve required notices and license terms.
- Modified files must carry appropriate change notices.
- The license is longer and more operationally detailed than MIT.

## Revisit when

Revisit only if project ownership, contribution policy, or a required dependency creates a documented licensing incompatibility. Any change requires a legal and contributor-impact review.
